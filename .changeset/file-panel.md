A file panel beside the terminal, shown and hidden with ⌘⇧E, lists the session's folder as a tree and opens its files to edit: edits save 3 seconds after you stop typing or at once with ⌘S, a file an agent changes updates in place, and when an agent changes a file with your unsaved edits, Hoot shows both versions and lets you pick which to keep.

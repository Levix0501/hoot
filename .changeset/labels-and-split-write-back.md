Issues now have labels, as in Linear, given and filtered on the list and the issue's page, managed on a new Labels page in the settings and with `hoot label`, and the built-in workflow's progress is the issue's label of the group Spec-driven, which the agent changes with `hoot issue edit` instead of `hoot step report`, writing a confirmed split back as sub-issues with `hoot issue create-batch` (formerly `hoot issue split`) so that the issue is completed once they are; an issue can have several sessions, opened with Start new session or `hoot session start`, cannot be started while it waits on other issues, and can be blocked by its parent or sub-issues.

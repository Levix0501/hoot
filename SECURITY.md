# Security policy

## Supported versions

Hoot is in alpha, so only the latest release gets security fixes. Please check that a problem still
happens in it before you report it.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Report them privately instead,
with [GitHub's private vulnerability reporting](https://github.com/Levix0501/hoot/security/advisories/new):
on the repository's **Security** tab, choose **Report a vulnerability**.

Say what an attacker could do and how to reproduce it, and include your Hoot version and system,
which **Copy** next to **Environment** in **Settings › About** puts on the clipboard. We will follow
up in the advisory.

What an agent does with the permissions you give it, such as in YOLO mode, which is on by default,
is how Hoot is meant to work, not a vulnerability in Hoot.
